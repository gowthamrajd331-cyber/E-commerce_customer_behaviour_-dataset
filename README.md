# E-Commerce Customer Behavior Analysis

## Description

This project analyzes e-commerce customer behavior and transaction data to identify purchasing patterns, sales trends, customer preferences, and factors affecting customer satisfaction. The project uses Python for data cleaning, exploratory data analysis, statistical analysis, and data visualization to generate meaningful business insights.

## Getting Started

### Dependencies

- Python 3.x
- Google Colab or Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Installing

- Download or clone this repository.
- Download the e-commerce dataset.
- Open the project notebook in Google Colab or Jupyter Notebook.
- Upload `ecommerce_customer_behavior_dataset.csv` to the notebook environment.

### Executing program
The project is executed in Google Colab by uploading the e-commerce dataset, importing the required Python libraries, loading the dataset using Pandas, and performing initial exploratory data analysis such as viewing the dataset, checking its dimensions, data types, information, missing values, and duplicate values.
